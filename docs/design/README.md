# Organisk – designreferanser

Designgrunnlaget, komponentkartet med 32 enkeltkomponenter og ikonregister v3 er levert med issue #23. `grunnlag/` beskriver farger og typografi, `komponenter/` inneholder kart, manifest og enkelt-SVG-er, og `ikoner/` inneholder ikonregister og originalfiler. Repoet bevarer de redigerbare SVG-ene; PNG-forhåndsvisninger og det redundante ZIP-arkivet finnes i issuevedleggene. Individuelle SVG-er er geometrisk referanse; eksempelinnhold bestiller ikke nye funksjoner.

Gjeldende avklaringer: bare mørkt tema i v1; hovedmenyen bruker hamburger; originalmodalen beholder OK/Avbryt; dialogfootere med 1/2/3 handlinger brukes nå, mens verdiredigerere uten OK/Avbryt kommer senere. Innstillinger vedlikeholdes i appen. Historiske Drive-lenker i katalogen er kildehenvisninger, ikke et parallelt dokumentsett.

Runtimeikonene i `assets/ui-icons/` følger de bevarte referanseformene og brukes gjennom appens felles ikonregister. Fontfiler og lisenser ligger i `assets/fonts/` (Fontsource Inter, Gentium Book Plus og Cousine, latin med norske tegn). Referansearkene er ikke runtime-ressurser.
