# Kontrollrapport – Komponentkart

- 32 navngitte komponenttyper, fordelt på seks komponentfamilier.  
- 32 redigerbare komponent-SVG-filer og 32 PNG-forhåndsvisninger.  
- Hver komponent-SVG kan parses som XML og rendres uten feil. Samtlige komponent-PNG-er kan åpnes.  
- Samtlige faktiske hex-farger i alle 32 komponent-SVG-ene og det samlede kartet finnes blant de tolv navngitte rollene i oppdatert designgrunnlag.  
- Kartet har navngitte komponenttyper, generell definisjon, varianter, ett illustrerende eksempel og fargeoversikt (navn og kode).
